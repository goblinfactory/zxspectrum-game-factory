# The original "shit brief"

This is the **raw stream-of-consciousness prompt** before running *"Improve this"* — the input that produced [FACTORY.md](../FACTORY.md).

Paste into any LLM, append **"Improve this."**, and compare the output.

---

> build me a factory AI harness for building spectrum games using common building blocks... ensure it has skills for artwork... create a team of specialist agent profiles, tester, artist, copywriter...

---

## Method

Described in full on the blog: [The "Shit Prompt" Method](https://alanhemmings.com/posts/2026-08-16-the-shit-prompt-method.html)

1. Dump the raw concept (60 seconds)
2. Append "Improve this."
3. Ship the open-source repo
4. Generate the obligatory 80s pixel art banner
5. Audit the gaps in what comes back
